# Dynamics365-AP-Implementation-2026
Accounts Payable Implementation Project using Microsoft Dynamics 365 Finance

Modern Electronics Distribution is a newly established legal entity created as part of this project.
This initiative aims to apply the practical knowledge and skills acquired during the Microsoft Dynamics Functional Consultant training program.
The project focuses on implementing the Accounts Payable module within Microsoft Dynamics 365 Finance & Operations to improve financial control, automate vendor transactions, and enhance overall operational efficiency.
